HTML

HTML is used to create the basic structure and content of a website. It defines elements such as headings, paragraphs, images, links, forms, and tables.

CSS

CSS is used to design and style web pages. It helps control colors, fonts, spacing, borders, layouts, animations, and the overall appearance of a website.

JavaScript

JavaScript adds functionality and interactivity to websites. It can be used to create buttons, forms, dynamic content, animations, and interactive web applications.

Bootstrap

Bootstrap is a popular CSS framework that provides ready-made components and responsive layouts. It helps developers create attractive websites quickly

Tailwind CSS

Tailwind CSS is a utility-first CSS framework that allows developers to design modern and responsive interfaces using predefined utility classes.

React JS

React JS is a JavaScript library used to build interactive user interfaces. It uses reusable components, making it easier to develop and maintain modern web applications.

Node JS

Node JS allows JavaScript to run on the server side. It is commonly used to create backend services, APIs, and server-based web applications.

MongoDB

MongoDB is a NoSQL database used to store application data. It stores information in flexible document-based structures and works well with modern web applications.
